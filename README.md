# Cover Story

A Roblox social-stealth extraction shooter, built with Rojo. Agents disguise themselves as NPCs in a crowd, steal intel,
crack a vault and extract with the Package.

- **New here?** Read `docs/PROJECT_STATUS.md` first: where the project stands, the document map, how to resume, and the
  owner's working agreements. Then `CLAUDE.md` (engineering rules) and `docs/BUILD_ORDER.md` (the plan).
- Source is in `src/` (server, client, shared), mapped by `default.project.json`. Tools come from `rokit.toml`
  (Rojo, StyLua, Selene). The map is generated from `src/server/Tools/Gala/`; the place file is not stored in the repo.
